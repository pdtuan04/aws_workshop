1. Go to S3 and create a new Bucket dedicated to storing deployment artifacts.
![overview](../../../images/5-Workshop/5.7-codedeploy/115.png)
2. Tick Block all public access and enable Bucket Versioning.
![overview](../../../images/5-Workshop/5.7-codedeploy/116.png)
3. After creating, create a folder by clicking Create Folder.
![overview](../../../images/5-Workshop/5.7-codedeploy/117.png)
4. Enter the name.
![overview](../../../images/5-Workshop/5.7-codedeploy/118.png)
Through the above steps, we have successfully created a place to store deployment artifacts.
![overview](../../../images/5-Workshop/5.7-codedeploy/119.png)
