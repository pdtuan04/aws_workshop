1. Select the temporary EC2 instance created previously, then navigate to **Actions** -> **Image and templates** -> **Create image**.
![overview](../../../images/5-Workshop/5.5-ec2/60.png)

2. Provide a name for the image.
![overview](../../../images/5-Workshop/5.5-ec2/61.png)

3. Click **Create image** to finalize the process.
![overview](../../../images/5-Workshop/5.5-ec2/62.png)

4. Navigate to the **AMIs** section to view the newly created image.
![overview](../../../images/5-Workshop/5.5-ec2/63.png)

Following the steps above, the AMI has been successfully created.
